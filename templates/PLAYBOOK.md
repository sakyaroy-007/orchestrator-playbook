## 3. 配置与 Git

- 员工默认继承自己的模型/思考，不复制总指挥配置；profile 按客户端保留默认。DSH 没有默认 profile，必须明确选择已有非交互 profile 或用户接受的 headless 推荐。
- 推荐与已应用分开；固定映射需适配器支持。未支持的要求阻塞启动。
- 并发/重型任务/超时/重试：config limits，不固定四并发。
- 提交/合并/推送/清理：config permissions 和 git；不能把 push 当发布许可。
- 集成分支/方式、推送节奏、保留策略与决定来源：【待填】。
- 非 Git：串行操作、本地恢复快照，不做 Git 操作。
