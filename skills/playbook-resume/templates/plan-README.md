## 5. 审查与整合

1. 对实际交付复核范围、完整 diff、变更说明与真实验收证据。
2. 对受影响行为跑必要检查，记录基线、dirty、命令、退出码、范围和缺口。
3. 获准且符合方法策略时受管整合，整合后核查实际结果；verified 与 integrated 分开记录。
4. 在仍是 owner 时同步看板/交接/决定。提交、推送、清理都按独立策略，无固定 no-ff、强制 push 或自动删 worktree。
5. 保护 dirty/未跟踪/ignored/未合并/活动/未知/承载证据成果，squash 无法证明整合时保留。
