# 变更说明（每张任务卡一份）

文件名用 `<卡号>.md`。执行者在自己分支的最后一个提交里写好；总指挥合并时，据此同步交接文档、根 `README.md`、看板和组件文档。

文件名按卡号唯一，多条分支并行也不会互相冲突。这就是执行者不直接改共享文档的原因。

**只写分支里真实发生的事**，审查时会逐条核对。

## 模板

```markdown
# <卡号> · <标题>

## 改了什么
- （3–8 条，具体到文件 / 端点 / 表）

## 怎么验证
- `命令` → 预期输出

## 文档影响
- `<文件>` 的「<小节>」需要改成：……
- （没有就写「无」）

## 遗留 / 后续
- ……
```
