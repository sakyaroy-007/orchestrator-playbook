# 交接文件与证据

真正的所有权变更按[生命周期](lifecycle.zh.md)。文件解释项目，编辑文件不能任命 owner。配置路径优先于以下规划路径示例。

## 事实来源

| 位置 | 用途 |
|---|---|
| `.orchestrator/config.json` | 可移植、有版本的目标、员工和操作策略 |
| 共享 Git common directory 的运行时，非 Git 为 `.orchestrator/local/` | 机器/会话身份、epoch、配置 revision、owner、尝试和恢复快照 |
| `.orchestrator/TEAM.md` | 带观察时间/revision 的可读花名册与所有权观察 |
| `.orchestrator/PLAYBOOK.md` | 项目工作流、资源约束与策略引用 |
| 配置指定的计划/卡/员工/交接文件 | 意图、有边界范围、决定、证据和下一步 |
| 任务日志、变更/审查记录 | 真实命令/结果及独立验收 |

运行时/恢复数据使用本地忽略规则。关联 worktree 共用状态，不能每个 worktree 各有 owner。已跟踪 TEAM.md、旧接任便签和锁年龄不能仲裁所有权。显式采用时保留旧文件，作为历史而不是 v3 运行时状态。

## TEAM.md 与 PLAYBOOK.md

TEAM 记录拍板人、观察到的 holder **会话 ID** 和客户端、epoch、配置 revision、日期、上次交接及员工 ID。花名册区分 CLI 发现、验证过的选项、登录就绪与实际执行。记录各员工继承自己的默认值或显式设置，推荐仍是建议；不放凭据，不复制私人 profile。

PLAYBOOK 指向 config，记录获准派发通道、整合/保留选择、热点文件、资源锁、测试方法和红线。复用共享流程，不抄整份技能。摘要与运行时冲突时以运行时为准，调查差异，不能改 holder 行抢位。

## 离任交接证据

调用 `handoff` 前记录：

- 目标、已完成范围、当前波次和明确的下一任务建议。
- 基线 HEAD/分支/worktree（或非 Git 描述）、dirty/未跟踪/ignored 事实、未推提交和本地恢复位置。Git 忽略的未跟踪文件不收进检查点，所需 ignored 证据先在获准范围内显式归档到会被覆盖的位置。unmerged index 或 dirty submodule 会被拒绝，特殊文件、超量/读取失败也可能留下 partial，要保留并如实报告，不能称为完整。先保存冲突各 stage 的所需内容并解决冲突，再正常 handoff，不能为通过检查抹掉 stage 内容。只有路径不证明快照完整。
- 每个 reserved/running/reported/unknown 任务：ID、尝试、员工、分支/worktree、最后提交、命令、日志、已知进程身份与剩余工作。
- 验证：命令、cwd、基线、退出状态、实际输出、覆盖范围、失败/跳过检查与缺口。预期输出写在验收里，不能拿它替代实际结果。
- 共享资源、后台服务、锁归属证据、未决决定，以及不能重复问的已定决定。
- 新会话需要的项目记忆，不含秘密和无关个人信息。

准备之前写意图和观察事实，不提前把新 owner 标为在任。成功后返回 handoff ID/目标并停止受管写入。ID 和完整检查点在权威运行时里，不为补写新 ID 再改检查点文件。失败/不完整快照不算已准备交接。提交/推送是项目策略选择，不是强制步骤。

## 接任清单

1. 读项目规则、配置交接、计划、看板、决定台账、员工规则和 config。
2. 读运行时 `status`/`doctor`，检查现场基线、日志、dirty 和进程身份。未知不等于不存在，不自动重启服务、员工或测试。
3. 按生命周期的已准备接任或明确恢复流程认领。用户调用已准备交接的 takeover 不重复问任命；恢复要有用户指示停止/替换，先保留任务并建立/核对恢复检查点。
4. 成功后把新 owner/epoch 和能力差异写入可读摘要，保留迟到结果，再派发前先核对。
5. 报告已就绪、运行中、未知、阻塞和有意保留的事项，不宣称客户端原生对话恢复或跨机锁。

## 冲突与成果保护

冲突会话停止受管修改，以运行时 owner/epoch 为准。不能通过改 TEAM.md、删锁、复制 ID 或等足时间获取角色。OS 锁保护单机协作受管操作，不隔离原始 shell/编辑器写入。

清理同时依赖策略与证据：dirty、未跟踪、ignored、未合并、运行中、未知或承载证据的成果保留。旧 force 不能绕过 v3 检查。squash 后工具无法证明已整合时，保留 worktree 等待明确核对。保留就报告为保留，不算交接失败。
